# @geastack/geaos

Installed-application runtime sources shared by GeaStack native targets that
host more than one app: the app manager and the installed-app registry.

```sh
npm install @geastack/geaos
```

A target that runs a launcher with installed apps compiles these sources in
through `@geastack/core`'s source manifest; the installed-app plan they read is
generated by `@geastack/core`'s build tooling. There is no JavaScript entry
point.
